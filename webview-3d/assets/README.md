# Diwan asset pipeline

Procedural, offline, no network. Proven in `docs/superpowers/spikes/2026-10-12-m1-pipeline.md`.

| Script                    | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm run assets:layout`   | `scripts/export-layout.ts` writes `worlds/<id>/layout.json` from the world's floor plan (seats via upstream `layoutToSeats`). The floor plan is the single source of layout for the renderer and the Blender bake.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `npm run assets:bake`     | `render-glyphs.mjs` first (headless Chromium renders the shaped Arabic and rasterises the logo into `worlds/house-of-wisdom/src/`), then Blender headless: `trim_bake.py` (shared trim sheets into `out/tex`), then `armillary.py` (the courtyard armillary sphere: its moving parts as named nodes, engraving textures, its own GLB), then `hall.py` (the House of Wisdom hall from `layout.json`: geometry, the armillary's plinth, lightmap UVs, both mood bakes, gobo, GLB). Override the binary with `BLENDER=/path/to/Blender`. `DIWAN_WORLD=<id>` (default `house-of-wisdom`) selects the world for `assets:layout`, `assets:bake` and `assets:optimize`: it picks `worlds/<id>/`, the `patterns.py` signal hue and guard (cobalt 226/25, House of Life amethyst 295/40) and, for any world but the House of Wisdom, `out/<id>/` for the shared trim sheets. The House of Wisdom's bake scripts are `trim_bake.py`, `armillary.py` and `hall.py`; `DIWAN_WORLD=house-of-life` runs `render-hieroglyphs.mjs` and `temple.py` instead (and `assets:optimize` then takes `pyramid.raw.glb` where the House of Wisdom takes the armillary). Extra args go after `--`; `-- --quick` bakes at 32 spp / 1024² for iteration. |
| `npm run assets:optimize` | `optimize.mjs` on the hall and the armillary: `worlds/house-of-wisdom/out/raw/{hall,armillary}.raw.glb` become `out/{hall,armillary}.glb`, and both raw lightmap PNGs become ETC1S KTX2 files. `node assets/optimize.mjs <in.glb> [out.glb]` and `--lightmap <in.png> [out.ktx2]` still work for any other asset.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `npm run assets`          | All three, in order.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Optimise chain

geometry passes, UASTC + RDO on normals and on brand-true colour (`BRAND_TRUE`: the logo panel, whose flat brand colours and edges ETC1S would block and shift), ETC1S on the remaining colour, AO and metallic-roughness, then Meshopt. The UASTC step runs in `optimize.mjs` with `ktx create` (the CLI skips RDO on normal maps) before the ETC1S pass, which leaves KTX2 textures alone. Lightmaps are separate KTX2 files (ETC1S, sRGB), one per mood.

Always `--simplify false --prune-attributes false`: the lightmap ships outside the GLB, so TEXCOORD_1 is referenced by no material and the default prune deletes it. Always `--flatten false`: the armillary's node tree is its motion (`polar_axis` > `cage` > `ecliptic` > `sun` ...). Mesh quantisation re-centres a mesh node's origin on its mesh, so the armillary's moving parts are empty pivots with their meshes as children.

## Files

- `blender/bl_common.py`, `patterns.py`: Metal GPU setup, mesh/image helpers, numpy ornament fields (Abbasid stucco band and field, blind-arcade frieze, lustre-tile dado, brick, plaster, cedar, grille) and the cobalt-hue guard every generated colour map passes.
- `blender/trim_bake.py`: trim-sheet bakes (stucco band, brick, Samarra field, frieze, dado: high-poly relief to normal + AO in Cycles; plaster and cedar in numpy).
- `blender/hall.py`: the House of Wisdom hall. Helpers: `hall_geom.py` (plan-coordinate geometry, booleans), `hall_textures.py` (star floor, brick floor, rug, marble, palette), `hall_dressing.py` (the Diwan Kufi بيت الحكمة relief, the J. Servo logo panel, the lustre planters; see `docs/superpowers/arabic-strings.md`), `hall_chambers.py` (the three themed north chambers, Yousef 2026-10-15: `chamber_chemistry`, `chamber_cartography`, `chamber_biology`, one node each with its props and hung sheets; `alcove-n-16` stays the study), `chamber_art.py` (their wall art in one 2048² atlas, drawn in numpy after period sources: an alembic on a furnace, a retort, a cucurbit and condenser, vessel studies; the al-Khwarizmi climates map, a south-up Balkhi disc, Baghdad's round city; Hunayn's eye, Dioscorides' plants, al-Jahiz's animals. No text and no letterforms: ruled bars stand in for writing. Seas are sea-green. The atlas passes a 40-degree cobalt guard; `python3 chamber_art.py <dir>` previews it without Blender). The in-world notice board bakes only when the layout has a `board` (none for now). `hall.meta.json` also lists the back palms' trunks (`palms`), so the runtime keeps the trunks still and sways only the fronds.
- `blender/armillary.py`: the courtyard armillary sphere (replaced the fountain at Yousef's request, 2026-10-12), exported as `out/armillary.glb`; the runtime turns its `cage`, `sun` and `moon` pivots (`src/world/armillary.ts`). Helpers: `armillary_spec.py` (dimensions, node frames: the polar axis at Baghdad's 33.3 deg, the ecliptic at 23.44 deg, the moon at 5.15 deg; parametric ring meshes; pure numpy, so `hall.py` builds the plinth and the fixed parts' bake-only shadow occluders from the same numbers), `armillary_textures.py` (degree scales, interlace and rosette bands, no script; the Old World globe from coded coastlines; both base colours pass the cobalt guard). Proportions were measured from a TRELLIS2 mesh, which is never committed.
- `render-glyphs.mjs`: Blender cannot shape Arabic, so headless Chromium renders it (and the logo SVG) to PNG. The font is Reem Kufi (SIL OFL 1.1), vendored with its licence in `fonts/`; only the rendered pixels are baked in. Its outputs and the logo source live in `worlds/house-of-wisdom/src/` (committed, so the exact lettering is reviewable; regenerated byte-identically on every bake). `worlds/house-of-wisdom/src/frieze_arabesque.png` (the glazed frieze band) is cropped from a pngtree stock strip: **licence unconfirmed — clear it or replace it with a code-generated band before any public release.**
- `blender/temple.py` (House of Life, E2 look-dev, 2026-10-18): the temple court in the Dendera manner from `worlds/house-of-life/layout.json`. Helpers: `bake_harness.py` (hall.py's bake harness, copied so hall.py stays untouched: materials, the shared UVLightmap atlas, sky/sun/lamp rig, join-and-split bake, dilation), `temple_parts.py` (the Hathor column after Description de l'Egypte Dendera Pl. 12: one mesh, built once at unit height and placed scaled for the six 7 m facade columns and the two 4.4 m colonnade columns; the cavetto cornice; the limestone obelisks; the complete pyramid, a four-faced casing under a gold pyramidion), `pyramid_spec.py` (the Great Pyramid's numbers, research.md 10c; the interior figures survive only for the Architects' papyrus drawing), `temple_textures.py` (numpy maps: ashlar sandstone, paving, the enclosure walls' painted elevation, the screen walls traced from Pl. 13 fig. 1 into painted relief, the column atlas with the Hathor face, the lintel title, granite, the pool's slate, Tura limestone, the obelisks' warm limestone, the title's glow map, the Architects' gridded papyrus, a palette; `python3 temple_textures.py <dir>` previews them with Pillow). Every colour map and both lightmaps pass the amethyst guard (nothing saturated within 255-335 deg), per texel and per 4x4 block (what ETC1S keeps). The pyramid, its pool, water, lilies and reeds are their own GLB (`pyramid.glb`, named nodes; `hall.meta.json` `centrepiece` gives it; `src/world/PoolFx.tsx` runs the water shader, caustics and bobbing lilies on the engine clock) but bakes into the hall's lightmaps, which the runtime applies to it (its meshes carry uv1). The noon sun is baked whole, so the live spot's gobo (`gobo_sun.png`) is black.
- `render-hieroglyphs.mjs`: the House of Life's only text, the title 𓉐𓋹 (pr-ꜥnḫ, U+13250 U+132F9), rendered with headless Chromium from the vendored Noto Sans Egyptian Hieroglyphs (SIL OFL 1.1, `fonts/`) into `worlds/house-of-life/src/title_pr_ankh.png`; the bake fills what the font's outlines enclose (even-odd) and carves it as sunk relief with a blue fill. No sign is drawn by hand. The reference plates (Description de l'Egypte, public domain) are in `worlds/house-of-life/refs/` (see `SOURCES.md`); only Pl. 13 fig. 1 is traced into the bake.
- `worlds/house-of-wisdom/out/` holds only the committed deliverables (`hall.glb`, `armillary.glb`, `lightmap_golden.ktx2`, `lightmap_dusk.ktx2`, `gobo_west.png`, `hall.meta.json`); the raw bake lives in `out/raw/`.
- `out/` is git-ignored (raw bakes stay local). Commit optimised outputs with `git add -f`.
- Each bake's `*.meta.json` is typed in `src/worlds/assetMeta.ts` (`parseWorldAssetMeta`).

## Bake timings: House of Wisdom hall

Apple M5 (10-core GPU), Cycles on Metal, kernels warm, Blender 5.2.2. Measured 2026-10-12 (Task 2b)
with `npm --workspace webview-3d run assets` on a quiet machine: **2 min 35 s** end to end (layout,
glyphs, bake, optimise). With a dev server and a parallel task sharing the GPU it took 3 min 09 s.

| Step                                                                 | Time   |
| -------------------------------------------------------------------- | ------ |
| `render-glyphs.mjs` (Chromium: Kufic + logo)                         | 0.3 s  |
| `trim_bake.py` (stucco, brick, Samarra field, frieze, dado; plaster) | ~29 s  |
| `armillary.py` (engraving and globe textures in numpy, GLB)          | 1.5 s  |
| hall: textures (numpy) + geometry (booleans, Kufic relief, planters) | 2.6 s  |
| hall: lightmap UV unwrap + pack, one 2048² atlas                     | 5.2 s  |
| golden: sky, direct + bounce (512 spp)                               | 15.3 s |
| golden: sun direct, window plugged (512 spp)                         | 4.7 s  |
| golden: sun bounce, window open (512 spp)                            | 29.3 s |
| dusk: sky, direct + bounce (512 spp)                                 | 15.5 s |
| dusk: 14 lamps, direct + bounce (512 spp)                            | 23.2 s |
| the cut sections, re-baked open (5 small passes)                     | 8.9 s  |
| gobo ray cast (numpy) + GLB export                                   | 0.4 s  |
| hall total, including Blender start-up                               | 115 s  |
| `optimize.mjs`: GLB chain (UASTC, ETC1S, Meshopt) + two lightmaps    | ~13 s  |

Everything bakes as one joined mesh and is split back by node afterwards: Cycles pays a set-up
cost per baked object, which with ~45 objects was ~14 s per pass. The first Cycles GPU run on a
machine also compiles Metal kernels (~114 s, once).

Outputs (2026-10-15, with the themed chambers and no notice board): hall 71,375 triangles (the
chambers 8,878), `hall.glb` 6.18 MB (the chamber art atlas is most of the 0.35 MB added);
`lightmap_golden.ktx2` 0.56 MB, `lightmap_dusk.ktx2` 0.61 MB; 8.0 MB of the 12 MB budget. The full
`npm run assets` took 2 min 40 s.

Outputs (2026-10-12, with the armillary): hall 63,081 triangles, `hall.glb` 5.83 MB; armillary
27,336 triangles, `armillary.glb` 0.40 MB (two texture sets: a 1024² ring atlas with base colour,
metallic-roughness and normal, a 1024x512 globe with base colour and metallic-roughness);
`lightmap_golden.ktx2` 0.55 MB, `lightmap_dusk.ktx2` 0.60 MB, `gobo_west.png` 0.20 MB: 7.59 MB of
the 12 MB budget. The hall bake itself took 125 s.
